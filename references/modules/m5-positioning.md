# М5. Позиционирование: документ, из которого вытекает весь GTM

**Место в нити:** точка входа — артефакты М4: берёшь самую сильную карточку гипотезы позиционирования и разворачиваешь её по шести элементам Dunford. Выход — заполненный фреймворк, из которого механически выводятся месседжинг (М6), каналы (М8), enablement (М9). В дереве целей М0 позиционирование — центральный узел: рычаги М11 ссылаются на элементы фреймворка, не на интуицию.

## Позиция курса: позиционирование ≠ слоган ≠ описание продукта

Три типовых не-ответа на вопрос «какое у вас позиционирование»: слоган («финансовый порядок для тех, кто думает о росте» — из него не следует ни цена, ни канал, ни скрипт), описание категории («SaaS-платформа для автоматизации отчётности» — не объясняет, почему выберут тебя), «в презентации где-то написано» (= не написано нигде).

Позиционирование отвечает на четыре вопроса сразу: для кого, в какой момент, почему выигрываешь у того, что клиент делал до тебя. Настолько конкретно, чтобы выводились решения: каналы, иерархия сообщений, первая фраза продавца. ✅-эталон: «Финдиры компаний с 3+ юрлицами в конце квартала выбирают нас вместо найма второго аналитика, потому что закрывают квартал силами текущей команды и проходят аудит без замечаний по регуляторным формам».

## Артефакт 1 (🔴 ядро): фреймворк Dunford — 6 элементов строго по порядку

Каждый следующий опирается на предыдущий. Застрял на элементе — сбой в предыдущем, не в этом. 40–60 минут с открытыми артефактами М1–М4.

**1. Конкурентные альтернативы.** Что клиент делал бы в точке слома, если бы тебя не существовало. Первый — потому что ценность существует только относительно альтернативы; без неё — описание функций. Разные альтернативы → разные ценности («терпит» → «надёжнее ручного героизма»; «нанимает» → «дешевле и без зависимости от человека»). Откуда: карта текущих решений М3 + карта потерь М4 (кто выше по доле — тот главная альтернатива). Финтех: главная битва против «потерплю» (~40%) и Excel (~23%), а команда по привычке пишет «мы лучше Конкурента А» — воюет за 10%, игнорирует 76%.

**2. Уникальные атрибуты.** Что есть у тебя, чего нет именно у альтернатив из элемента 1 — не весь список фич. Откуда: зона «уникальны» матрицы М4, отфильтрованная под альтернативы. Финтех: автосборка 6 часов вместо 4 дней, автосверка до аудитора, процесс без привязки к человеку, регуляторные формы из коробки. «Единое окно из 5 систем» НЕ идёт — честный разрыв из М4: клиент поймает на третьем вопросе демо, и дальше не верит ничему, включая правду.

**3. Ценность для клиента.** Что атрибуты означают для бизнеса. Лестница от функциональной выгоды к бизнес-результату — подниматься до конца: финдир считает деньги и риск, часы его не трогают. ❌ «6 часов вместо 4 дней» (процесс) → ✅ «закрываете квартал силами текущей команды и проходите аудит без замечаний — даже на третьем юрлице» (деньги, риск, масштаб — язык защиты бюджета перед советом директоров). Откуда: desired gains правой части VPC (М1) + строки «устранение причины» карты соответствий (М2).

**4. Кому важнее всего.** Характеристики, делающие ценность максимально острой прямо сейчас. Демография не входит — она описывает рынок, боль живёт в человеке. ❌ «финотделы компаний 16–200 человек» → ✅ «финдиры компаний с 3+ юрлицами, данные в 5 системах, отчётность вручную, объём только что вырос». Откуда: суперсегменты М2 (кластер с наибольшей конверсией и удержанием) + push-блок JTBD-интервью.

**5. Категория.** Ментальный контекст, в котором ценность понятна без объяснений. См. блок ниже — самое дорогое решение.

**6. Тренды (опционально).** Внешние силы, делающие ценность острее сейчас. Тренд должен быть настоящим — иначе слайд про «цифровизацию». Откуда: контекст рынка М1 + внешний триггер М3. Финтех: ужесточение требований ЦБ с Q3 (гонит волну к точке слома по календарю) + дефицит аналитиков (чем дороже наём, тем сильнее «квартал без второго аналитика»).

## Категория — решение, которое стоит дороже всего

Клиент кладёт продукт в ментальную папку автоматически — до сайта, до демо. Папка запускает два механизма:

**Ценовой якорь** (Канеман: оценивая незнакомое, человек цепляется за первую знакомую цифру). Папка «инструмент для финотдела» — якорь 3–10К/мес, сравнивают с подписками. Папка «замена ручной отчётности для CFO» — якорь сдвигается к стоимости найма аналитика, 80–120К/мес. Продукт один, разговор о деньгах принципиально другой. Выбирая категорию, выбираешь ценовой коридор.

**Ожидания на демо.** Папка диктует вопросы клиента. «Бухгалтерский SaaS» → «какие интеграции, сколько на пользователя?» — продавец в обороне с первой минуты. «Замена ручной отчётности для CFO» → «закрою ли квартал без найма?» — разговор сразу про результат.

**Категорию нельзя просто написать на сайте.** Её создают сигналы: цена, каналы, кейсы, партнёры, язык. Написал «замена ручной отчётности», но продаёшь через SEO по «бухгалтерский SaaS» с тарифами как у SaaS — клиент положит в старую папку. Сигналы громче заголовка. Переопределить категорию = поменять сигналы, операционная работа на месяцы.

## Зоны ответственности PMM (позиция курса — честность про контроль)

- **Контролирует напрямую:** месседжинг, канальная стратегия, контент, sales enablement — при заполненном фреймворке пишутся почти механически.
- **Влияет, но не решает:** продуктовый роадмап (даёт инпут: важное сегменту, разрывы; решает продуктовая команда).
- **Должен знать, но не устанавливает:** цену. Обязан понимать ценовой якорь категории — «окупается быстрее месяца зарплаты аналитика» работает, только если знаешь реальные 80–120К.

PMM, который лезет в чужую зону, теряет доверие. PMM, который чётко работает в своей, создаёт рычаг.

## Позиционирование → GTM: карта следствий

| Элемент | Что определяет в GTM |
|---|---|
| Конкурентные альтернативы | Скрипт продаж: против чего аргументируем, какие возражения ждём |
| Уникальные атрибуты | Battle cards, sales enablement (М9) |
| Ценность | Иерархия сообщений (М6) |
| Кому важнее всего | ICP, таргетинг, квалификация лида |
| Категория | Канальная стратегия (М8) |
| Тренды | Тайминг кампаний, контентная стратегия |

Финтех-цепочка: категория → каналы уходят из SEO в сообщества финдиров и сезонный контент за месяц до конца квартала; альтернатива → продавец открывает звонок «сколько дней закрывали прошлый квартал и сколько юрлиц» (активирует точку слома); ценность → «окупается быстрее месяца зарплаты аналитика» вместо сравнения с Конкурентом А; сегмент → квалификация лида (финдир с одним юрлицом — пока не целевой). Без отдела продаж «первый вопрос» переезжает на первый экран сайта и в первое письмо после регистрации — логика та же, носитель другой.

## Артефакт 2 (🔵): три GTM-следствия

Из фреймворка вывести конкретные следствия для месседжинга, каналов, первого касания — каждое тянется к элементу и превращается в задачу на понедельник. «Везде» — это нигде; «выявляем потребности» не активирует точку слома. Хотя бы одно следствие должно что-то исключать.

## Артефакт 3 (🔵): три теста принятого решения

Отличают решение от слайда в общей папке:
1. **Тест последствий** — выводятся ли три конкретных GTM-следствия? Не выводятся — позиционирование сформулировано, но не принято; ищи буксующий элемент.
2. **Тест «нет»** — «что мы точно НЕ делаем?» Позиционирование, которое ничего не исключает, — не позиционирование. Финтех-ответ: «первый экран, питч и контент — для финдиров, не для бухгалтеров-исполнителей».
3. **Тест коридора** — коллега, не работавший над позиционированием, за 30 секунд пересказывает: кто клиент, в какой момент приходит, вместо чего выбирает. Место запинки = слабый элемент (не назвал для кого — элемент 4; не назвал вместо чего — элемент 1). В М6 тест вернётся с готовым текстом питча.

## Типовые ошибки М5
1. Слоган вместо позиционирования
2. Альтернативы только прямые (потеряны ~76% реальных потерь)
3. Атрибуты не отфильтрованы под альтернативы (список всех фич)
4. Ценность застряла на функциональной выгоде
5. Сегмент = рынок, не человек в точке слома
6. Категория повторяет описание продукта и якорит цену вниз
7. Честный разрыв вынесен в атрибуты
8. Категория «переопределена» строчкой на сайте при старых сигналах
9. Фреймворк заполнен не по порядку / элементы из воздуха
10. Ни один тест не проведён — слайд в общей папке

## Гейты
- Фреймворк требует артефактов М1–М4 (каждый элемент прослеживается: альтернативы ← М3/М4, атрибуты ← матрица М4, ценность ← VPC М1 + карта соответствий М2, сегмент ← суперсегменты М2, тренды ← М1/М3)
- Гипотеза из М4 — вход; без неё фреймворк собирается из мнений

## Что нести в М6
Заполненный фреймворк — без него месседжинг делать не из чего. Критерий готовности: из «категории» выводится конкретный канал, коллега проходит тест коридора.
