# Инструмент разбора: фреймворк Dunford (+ три GTM-следствия, три теста)

Грузи при разборе любого артефакта М5. Рубрика — единственный источник вердикта. Полный текст, ❌/✅ и тетрадь — `modules/m5-positioning.md`.

## Место в нити
**Вход:** карточка гипотезы + матрица + карта потерь (М4), VPC и карта соответствий (М1–М2), суперсегменты и push (М2), триггеры и контекст рынка (М1, М3). **Выход:** канвас VP (М6) — без заполненного фреймворка месседжинг делать не из чего; категория → канальная стратегия (М8); элементы → рычаги дерева (М11).

## Гейт перед разбором
Фреймворк без артефактов М1–М4 = собран из мнений. Если элементы не прослеживаются к артефактам — разбор начинается с недостающего фундамента, не с формулировок.

## Рубрика: 6 элементов (🔴) — проверять строго по порядку; сбой на N ищи в N−1

| Элемент | Проверка | Типовая ошибка | Наводящий вопрос | Эталон |
|---|---|---|---|---|
| 1. Конкурентные альтернативы | Из карты потерь М4 по долям + карты текущих решений М3; статус-кво присутствует | Только прямые конкуренты (потеряно ~76% реальных потерь) | Что клиент делал бы в точке слома, если бы вас не существовало? Кто №1 по доле в карте? | «Потерплю ~40%, Excel ~23%, найм ~13%; конкурент А — 10%, не главная битва» |
| 2. Уникальные атрибуты | Из зоны «уникален» матрицы, отфильтровано под альтернативы элемента 1; честный разрыв НЕ здесь | Список всех фич; «удобный интерфейс»; разрыв в атрибутах | Чего именно нанятый аналитик / Excel дать не может? Что клиент поймает на демо? | «Автосборка 6ч вместо 4 дней; процесс без привязки к человеку; формы из коробки» |
| 3. Ценность | Дошла до бизнес-результата (деньги, риск, масштаб); из desired gains + «устранение причины» М2 | Застряла на функциональной выгоде («экономит время», «6 часов вместо 4 дней») | Что финдир скажет совету директоров, защищая бюджет? | «Закрываете квартал текущей командой и проходите аудит без замечаний — даже на третьем юрлице» |

| 5. Категория | Осознанный выбор папки: назван ценовой якорь и ожидания на демо; сигналы (цена, каналы, кейсы) не противоречат | Категория = описание продукта, якорит вниз; «новая категория» строчкой на сайте при старых сигналах | Какую цену клиент сочтёт нормальной в этой папке? С каким вопросом придёт на демо? | «Замена ручной отчётности для CFO: якорь 80–120К (найм), не 3–10К (SaaS)» |

## Рубрика: три GTM-следствия (🔵)

| Поле | Проверка | Типовая ошибка | Наводящий вопрос |
|---|---|---|---|
| Каждое следствие | Тянется к конкретному элементу и превращается в задачу на понедельник | «Будем везде», «выявляем потребности» | Из какого элемента это следует? Какую задачу поставишь в понедельник? |
| Исключение | Хотя бы одно следствие что-то исключает | Ничего не исключено = решения нет | Куда НЕ идём, что НЕ говорим, кому НЕ продаём? |

## Рубрика: три теста (🔵)
Последствий: три следствия выводятся → принято; не выводятся → назвать буксующий элемент. «Нет»: коллега называет, что точно не делаем; не может → ограничений нет. Коридора: коллега вне проекта пересказывает за 30 секунд (кто, в какой момент, вместо чего); запинка = слабый элемент (не назвал для кого → элемент 4; вместо чего → элемент 1).

## Деградация по данным
**Нет карты потерь (М4 пропущен):** элемент 1 собирается из карты текущих решений М3 + интервью, помечается гипотезой; вернуться, когда наберутся 10 потерь. **Продукт не запущен:** весь фреймворк — гипотеза с планом проверки через интервью с формулировкой (метод из М4/М7).

## Частые вердикты
- Заполнено не по порядку / элементы не ссылаются на артефакты → «Переделать» с элемента 1.
- Ценность = функциональная выгода → вернуть с лестницей «процесс → деньги/риск/масштаб».
- Категория повторяет описание продукта → вопрос про якорь: «с чем клиент сравнит цену в этой папке?»
- Все шесть заполнены, но ни один тест не проведён → «Доработать»: минимум тест коридора с живым человеком.
